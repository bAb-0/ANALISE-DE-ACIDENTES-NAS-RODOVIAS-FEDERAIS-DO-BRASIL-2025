# Análise dos Acidentes nas Rodovias Federais do Brasil — 2025

## 📊 Sobre o Projeto

Este projeto apresenta uma análise de dados sobre acidentes ocorridos nas rodovias federais brasileiras no ano de 2025.

A análise está sendo desenvolvida utilizando Power BI, com base em dados públicos disponibilizados pela Polícia Rodoviária Federal (PRF). O objetivo é explorar padrões e características das ocorrências por meio de visualizações e dashboards interativos.

## 🎯 Objetivo

Explorar e visualizar dados de acidentes nas rodovias federais brasileiras em 2025, buscando identificar padrões de ocorrência ao longo do tempo.

## 🗂 Fonte dos Dados

Os dados utilizados neste projeto são provenientes da base pública de acidentes da Polícia Rodoviária Federal (PRF).

Base de dados oficial:
https://www.gov.br/prf/pt-br/acesso-a-informacao/dados-abertos/dados-abertos-da-prf?utm_source=chatgpt.com

A base contém registros detalhados das ocorrências, incluindo informações como:

* data do acidente
* horário da ocorrência
* dia da semana
* período do dia
* localização do acidente
* características da via
* fatores relacionados ao evento

Essas informações permitem realizar diferentes análises sobre o comportamento dos acidentes nas rodovias federais brasileiras.

## 🛠 Ferramentas Utilizadas

* Power BI — criação dos dashboards e análise visual dos dados
* CSV — formato do conjunto de dados utilizado
* GitHub — versionamento e documentação do projeto

## 📊 Dashboard Desenvolvido

### Análise Temporal dos Acidentes — 2025

Este dashboard apresenta uma análise temporal dos acidentes registrados em 2025, explorando quando as ocorrências acontecem.

Principais visualizações presentes no painel:

* acidentes por período do dia
* acidentes por dia da semana
* acidentes por mês

O objetivo dessa análise é identificar padrões temporais e possíveis períodos com maior concentração de acidentes.

## 🖼 Visualização do Dashboard

![Dashboard Análise Temporal](imagens/dashboard-temporal.png)

Visualização do dashboard desenvolvido no Power BI apresentando a distribuição temporal dos acidentes registrados em 2025.

🔎 Principais Insights

A análise inicial dos dados permite identificar alguns padrões relevantes:

• Maior concentração de acidentes no período da tarde, possivelmente associada ao aumento do fluxo de veículos em horários de retorno do trabalho.

• Elevação das ocorrências durante o final de semana, especialmente aos sábados e domingos, indicando influência de deslocamentos para lazer e viagens.

• Aumento expressivo no número de acidentes nos últimos meses do ano, possivelmente relacionado ao maior fluxo de veículos nas rodovias durante o período de festas e comemorações de final de ano.
